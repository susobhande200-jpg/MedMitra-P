# MedMitra fixes — 22 October 2026

## Included changes

- Consistent, visible checkbox/radio selected states across forms, including the pharmacy fulfilment options. The existing Bootstrap checkbox SVG is now paired with an explicit accent background so a checked tick does not disappear on a white background.
- Medicine listing form supports either selecting an active catalogue medicine or using an inline “Add a medicine that is not in the catalogue” flow. The new medicine can capture a name, generic name, strength, product form, pack size, manufacturer, category, prescription flag, and optional catalogue image. The store listing has its own optional image.
- Pending pharmacies may prepare inventory while waiting for verification. Listings are still excluded from public search until the pharmacy is approved; rejected and suspended pharmacies cannot add/edit new marketplace inventory.
- The Featured Offers admin editor now exposes only the image upload and optional destination link. The homepage promotion rail is image-only; no promotional titles, descriptions, or button copy are shown.
- Fixed the light refresh stylesheet so it no longer assigns light theme variables to `data-theme="dark"`. Added dark-mode-only refinement CSS; light-mode rules were not redesigned.

## Runtime test notes

The environment used to prepare this archive had no network access and Django was not installed, so the Django test suite could not be executed here. Python syntax compilation, template block-balance checks, CSS parsing (where a CSS parser was available), ZIP integrity, and SQLite integrity are checked during packaging. Run `python manage.py check`, `python manage.py makemigrations --check --dry-run`, and `python manage.py test` locally before deployment.

# MedMitra project structure

- `config/`: Django settings and root routes
- `accounts/`: customer registration, email verification and pharmacy staff roles
- `marketplace/`: medicine catalogue, pharmacy stores, cart, medicine orders, prescription review and pharmacy verification
- `pharmacy/`: internal inventory, stock movements, batch expiry alerts and point-of-sale counter sales
- `profiles/`: customer/store account settings, saved items, address book and privacy controls
- `templates/`: shared page shell and pharmacy/customer/staff pages
- `static/css/`: pharmacy marketplace styling
